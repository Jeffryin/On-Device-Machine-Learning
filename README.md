# On-Device-Machine-Learning
Our plan is to take a public lego dataset that contains images and annotations, which are bounding boxes in respect to each lego piece in each image. We will need to convert the VOC(.xml files) into .txt files. With the .txt files we can then train a YoLo model on this dataset to classify lego pieces in an image frame. After confirming that we like where the accuracy % is, we will then run inference on a Jetson Nano board with a camera connected to it. The expected result will be that any lego piece that the camera sees, should ideally draw a bounding box and label the lego piece.
